==============================================================
  Fx Live 24/7 - Setup & Run Commands (Windows)
==============================================================

PREREQUISITES:
  1. Install Node.js (v18 or higher) from https://nodejs.org
  2. Install FFmpeg from https://ffmpeg.org/download.html
     (Make sure ffmpeg is added to your system PATH)

--------------------------------------------------------------
STEP 1: Open PowerShell/Terminal and go to the project folder
--------------------------------------------------------------

  cd D:\Software\Fx-Live

--------------------------------------------------------------
STEP 2: Install all dependencies
--------------------------------------------------------------

  npm install

--------------------------------------------------------------
STEP 3: Setup the database
--------------------------------------------------------------

  npm run db:setup
  npm run db:migrate

  (Or run both together with: npm run setup -- but this will
   also run npm install again, which is fine)

--------------------------------------------------------------
STEP 4: Configure environment variables
--------------------------------------------------------------

  Copy .env.example to .env.local and edit it:

  copy .env.example .env.local

  Then open .env.local in a text editor and update:
    - SESSION_SECRET  (any random 32+ character string)
    - ADMIN_USERNAME  (your login username)
    - GOOGLE_CLIENT_ID  (if using Google Drive)
    - GOOGLE_CLIENT_SECRET  (if using Google Drive)
    - GOOGLE_REDIRECT_URI  (your domain + /api/google-drive/callback)

  To generate a password hash for login, run:

    node scripts/generate-password-hash.js YourPassword

  Then put the generated hash in .env.local as:
    ADMIN_PASSWORD_HASH=<the-generated-hash>

--------------------------------------------------------------
STEP 5: Run in Development Mode
--------------------------------------------------------------

  npm run dev

  Then open http://localhost:3000 in your browser.

--------------------------------------------------------------
STEP 6: Run in Production Mode
--------------------------------------------------------------

  npm run build
  npm run start

  The app will be available at http://localhost:3000

--------------------------------------------------------------
OPTIONAL: Run with Docker
--------------------------------------------------------------

  docker-compose -f docker-compose.production.yml build
  docker-compose -f docker-compose.production.yml up -d

==============================================================
  QUICK REFERENCE (All Commands Summary)
==============================================================

  npm install                 → Install dependencies
  npm run db:setup            → Create database tables
  npm run db:migrate          → Run database migrations
  npm run dev                 → Start dev server (port 3000)
  npm run build               → Build for production
  npm run start               → Start production server
  npm run generate-password   → Generate password hash
  npm run setup               → Full setup (install + db)
